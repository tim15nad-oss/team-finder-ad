# TeamFinder

TeamFinder — веб-платформа для поиска единомышленников в Pet-проектах. Разработчики, дизайнеры и другие специалисты публикуют идеи проектов, указывают нужные навыки и собирают команду, а остальные пользователи откликаются на участие.

## Возможности

**Пользователи**
- Регистрация и вход по email и паролю.
- Профиль: имя, фамилия, аватар, «о себе», телефон, ссылка на GitHub.
  Если аватар не загружен, он создаётся автоматически из первой буквы имени.
- Редактирование профиля и смена пароля.
- Список всех участников (12 на странице, новые сверху).

**Проекты**
- Создание и редактирование проекта: название, описание, ссылка на GitHub, статус (открыт или закрыт).
- Главная страница со списком проектов (12 на странице, новые сверху).
- Присоединение к проекту и выход из него, список участников.
- Завершение проекта автором.
- Необходимые навыки проекта: автор добавляет и удаляет их без перезагрузки страницы, поле ввода подсказывает существующие навыки или создаёт новый.
- Фильтр проектов по навыку (`?skill=<название>`).

**Права доступа**
- Гость: просматривает проекты, профили и создаёт аккаунт.
- Авторизованный пользователь: создаёт, редактирует и завершает свои проекты, участвует в чужих.
- Администратор (`/admin/`): управляет пользователями, проектами и навыками, меняет пароли, блокирует и удаляет аккаунты.

## Стек

- Python 3.10, Django 5.2
- PostgreSQL 16 в Docker
- Pillow (генерация аватаров), psycopg2, python-decouple
- HTML, CSS, JavaScript без фреймворков

## Структура проекта

```
team_finder/        настройки, корневые URL, общие константы и функции
users/              пользователи: модель, формы, регистрация, профиль, аватары
projects/           проекты и навыки, участие, JSON-запросы
templates_var3/     HTML-шаблоны
static/             CSS, JS, шрифты, изображения
media/              загруженные аватары (создаётся автоматически)
```

## Как развернуть проект

Нужны Python 3.10, Docker с запущенным демоном и Git.

### 1. Виртуальное окружение

```bash
python -m venv venv
```

Активация:

- Windows (PowerShell): `venv\Scripts\Activate.ps1`
- Windows (cmd): `venv\Scripts\activate`
- Linux/Mac: `source venv/bin/activate`

Установка зависимостей:

```bash
pip install -r requirements.txt
```

### 2. Файл `.env`

Скопируйте пример и заполните своими значениями:

```bash
cp .env_example .env        # Linux/Mac
copy .env_example .env      # Windows
```

| Переменная              | Что указать |
|-------------------------|-------------|
| `DJANGO_SECRET_KEY`     | Случайная строка. Сгенерировать: `python -c "from django.core.management.utils import get_random_secret_key as g; print(g())"` |
| `DJANGO_DEBUG`          | `True` для разработки, `False` для запуска |
| `DJANGO_ALLOWED_HOSTS`  | Разрешённые хосты через запятую, по умолчанию `localhost,127.0.0.1` |
| `POSTGRES_DB`           | Имя базы данных, например `team_finder` |
| `POSTGRES_USER`         | Пользователь PostgreSQL |
| `POSTGRES_PASSWORD`     | Пароль пользователя PostgreSQL |
| `POSTGRES_HOST`         | `localhost` при локальном запуске |
| `POSTGRES_PORT`         | Порт базы на вашем компьютере, по умолчанию `5432` |

### 3. База данных в Docker

```bash
docker compose up -d
```

Проверка: `docker compose ps` должен показать статус `Up`. Остановка: `docker compose down`.

- Если порт 5432 занят (например, локальным PostgreSQL), замените в `docker-compose.yml` строку `"5432:5432"` на `"5433:5432"` и поставьте `POSTGRES_PORT=5433` в `.env`.
- Значения `POSTGRES_USER` и `POSTGRES_PASSWORD` записываются в базу при первом создании тома. Если вы изменили их позже, пересоздайте том (данные будут удалены): `docker compose down -v`, затем `docker compose up -d`.
- При ошибке `permission denied while trying to connect to the Docker daemon socket` на Linux добавьте `sudo`.

### 4. Миграции и администратор

```bash
python manage.py migrate
python manage.py createsuperuser
```

`createsuperuser` запросит email, имя, фамилию и пароль.

### 5. Запуск

```bash
python manage.py runserver
```

Сайт доступен по адресу <http://localhost:8000> и ведёт на список проектов.
